# Wendi Ji — portfolio

Wendi Ji's professional portfolio, published at [wendyj92.github.io](https://wendyj92.github.io/).

## Contents

- Four key skill areas, with links to relevant career experience.
- A reverse chronological career timeline, with resume-based employment dates and an MSc education milestone.
- An MSc coursework case study in Bayesian inference and classification, with a comparison of reported test results from six model configurations.
- Education, professional credentials and supporting tools.
- A project delivery dashboard with project/status filters, planned versus forecast or actual finish dates, overdue tasks and a filtered CSV export.
- An operations reporting example with monthly filtering and a CSV download.
- Responsive styles, semantic navigation and a CSV download.

No build step or dependencies are required. Open `index.html` locally to preview.

Both interactive demonstrations use synthetic data and are written in JavaScript. They are separate from the professional experience summaries and contain no employer data.

The [MSc project](https://wendyj92.github.io/#academic-project) summarises MTHM017: Advanced Topics in Statistics. Its methods and figures come from the supplied coursework report, rather than the synthetic dashboard data. Classification scores follow printed R outputs and confusion matrices on pages 45–53 where the prose differs (RBF SVM: 85.6%). These are results from one 750/250 train/test split, not a new benchmark or a rerun. The page includes methodological limitations and further development ideas; the original report and source datasets are not bundled with the site.

The project dashboard uses a fixed 30 September 2026 snapshot and calendar-day delays so its results are reproducible. Headline metrics follow the selected project; the status filter controls the chart, task table and CSV export.
