# Wendi Ji — portfolio

Static portfolio prepared for the `WendyJ92.github.io` GitHub Pages repository.

## Contents

- Professional experience summaries based on Wendi Ji's CVs.
- An interactive browser-based reporting example using explicitly synthetic data.
- Responsive styles, semantic navigation and a CSV download.

No build step or dependencies are required. Open `index.html` locally to preview.

The demonstration is written in JavaScript. It is not a Python, SQL or Tableau project, and it does not contain employer data.

## GitHub Pages

Target URL: [https://wendyj92.github.io/](https://wendyj92.github.io/).

In the `WendyJ92.github.io` repository, open **Settings → Pages** and choose **Deploy from a branch**, branch `main`, folder `/ (root)`. The site becomes available after a successful GitHub Pages deployment.
