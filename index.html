FEOBAWAVE LIMITED · PROFESSIONAL EXPERIENCE

Correcting store attribution in Python

  • Python
  • LLM APIs
  • Excel / CSV
  1. 01 / THE PROBLEM

    Missing stores.

    AI-generated Python logic excluded stores with more than one historical sales representative. That rule did not reflect how store relationships changed over time.

  2. 02 / MY CONTRIBUTION

    Review the logic.

    I identified and corrected the faulty logic, cross-checked the results using a second LLM, and documented a review procedure.

  3. 03 / THE RESULT

    Keep both views.

    The corrected processing retained historical sales relationships and assigned each store to its most recent representative, resolving the store-exclusion error.

How I choose the toolFor store classification, sales analysis, cleaning and extraction, I select between API automation and conversational AI according to task complexity, output quality and cost.
