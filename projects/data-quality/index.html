Data Cleaning & Quality Validation

Correcting a Python workflow that omitted stores with multiple historical sales representatives.

FEOBAWAVE LIMITED · UK

The issue

I use Python and LLM APIs to process Excel and CSV files for store classification, sales analysis and data cleaning. In one workflow, AI-generated Python code excluded stores that had more than one sales representative in their history.

The filtering rule removed valid stores instead of keeping their changing sales relationships.

What I changed

  • Traced the exclusion to the filtering logic and corrected it.
  • Preserved historical sales relationships while assigning each store to its most recent representative.
  • Cross-checked the results with a second LLM and documented the review steps.

The result

The corrected process retained the previously excluded stores. It kept the history needed for sales analysis while providing a current representative for each store.
